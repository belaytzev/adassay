22% of the product pages an agent reads carry declared advertising.

We asked Google 50 questions people put to an agent before buying something, read the top ten results the way an agent does, and counted what each publisher itself marked as commercial: sponsored links, affiliate links, promo codes, paid-placement notices. Ten control questions with no product in them turned up none. Advertising that carries no marker is not counted, so every number here is a floor.

Cut and queried are different things

A segment is cut when it is the advertisement: a price button, a "View at Best Buy", a promo code. A review paragraph that links the product it discusses is queried instead. It stays in the text with a marker, because it still holds the review. Nearly all the cut text, 96.5% of it, carries rel="sponsored"; the rest is paid-placement notices. Nearly all the queried text carries an affiliate link.

IPVanish offers 3,400-plus servers in 113 countries, which is in the same ballpark as NordVPN, Proton VPN, ExpressVPN and Surfshark. In our experience, IPVanish’s internet download speeds were uneven, with a 44% average internet download speed loss in our 2024 testing, with fast speeds marred by occasionally noticeable dips, which could impact gaming or 4K streaming.

IPVanish works fine for casual use, but you can get a VPN with more robust privacy features and faster internet speeds, all of which benefit travel. IPVanish’s user-friendly apps make it a decent choice for beginners seeking a VPN to add peace of mind and allow for streaming abroad. But wallet-friendly VPNs PIA and Surfshark are better options for the money because of their larger server networks.

What the first pass got wrong

Version 0.2.1 cut a whole paragraph for one sponsored link anywhere in it. A hand check of 100 random cuts found 16 review paragraphs among them: a LastPass breach history, an IPVanish speed-test loss, advice to cancel a VPN before it renews. They made up 70% of the text cut. Version 0.2.2 cuts only a segment that is the link and queries the prose around one. The same check on the new run found 3 short lines that were themselves the link (a price, a spec, a plan description) and no review paragraph.

How it was measured

60 queries, ten in each of five buying categories and ten control. The top ten Google results for each, through SearXNG, deduplicated: 593 pages, frozen in urls.txt so a rerun reads the same ones. Each page was read on 28 September 2026 from a residential address in Spain with adassay 0.2.2, rules only: no model judge, no shared database, an empty local database per page. The queries, the URLs, per-segment verdicts without text and the scripts are in research/2026-10-ads.
