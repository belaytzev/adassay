An ad blocker for AI agents.

Web pages carry text written to be quoted by machines: affiliate inserts, paid placements dressed as editorial, instructions hidden where only a parser will find them. adassay cuts what the publisher declared, marks what is doubtful, and reports what the page hides from readers.

or open a saved one:

It removes advertising the publisher itself declared, and it has never removed an honest paragraph — the one number the project refuses to trade away. It does not reliably catch native advertising that carries no link, no price and no disclosure. That class is an open problem, not a solved one.

Nothing you paste here is stored. This page opens no database and tells the shared server nothing.
